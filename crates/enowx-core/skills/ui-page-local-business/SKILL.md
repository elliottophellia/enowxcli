# Local business or service page

One kind of page. The measures (container, grid, spacing, type) are in
`ui-layout`; each part it uses (header, hero, table, form) has its own
`ui-part-*` skill. Start from this skeleton, then cut and reorder for the
content.

The visitor wants to know: what, where, when, how much, how to book. Put
those in the first screen: name and what it is, the booking action, and a
compact block with address, hours and phone. Then services with prices,
location with a map link, and the booking steps. No slogans before facts.
